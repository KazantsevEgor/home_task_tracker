# Сервис домашних задач

Консольное приложение для планирования и контроля домашних дел.

## Возможности

- просмотр списка задач;
- поиск задачи по названию;
- фильтрация по категории;
- сортировка задач по дедлайну;
- добавление новых задач;
- отметка задачи выполненной;
- снятие отметки выполнения.

## Структура проекта

- `main.py` — точка запуска, меню, вывод задач;
- `tasks.py` — функции работы с задачами (поиск, фильтрация, сортировка);
- `completions.py` — функции выполнения задач и проверки статуса;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/tasks.json` — хранилище задач;
- `tests/` — автоматизированные тесты.

## Формат данных

Задачи хранятся в `data/tasks.json` в виде списка словарей:

```json
[
  {
    "id": 1,
    "name": "Убрать кухню",
    "category": "Уборка",
    "deadline": "2026-09-17",
    "is_completed": false
  }
]
```

## Требования

- Python 3.x;
- pytest;
- flake8.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```
