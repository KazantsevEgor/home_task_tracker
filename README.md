# Название проекта
Сервис домашних задач

## Назначение
Приложение предназначено для планирования и контроля домашних дел. Пользователь
может создавать задачи, назначать сроки и отслеживать их выполнение.

## Целевая аудитория
Семьи, пары и люди, которые живут вместе и хотят удобно распределять домашние
обязанности.

## Предметная область
Предметная область проекта связана с организацией бытовых задач: уборкой,
покупками, ремонтом и другими регулярными делами по дому.

## Основные сущности
- Пользователь — участник, который создает и выполняет задачи.
- Задача — домашнее дело с названием, описанием, сроком и статусом.
- Категория — группа задач, например уборка, покупки или ремонт.

## Основные функции
- Создание, изменение и удаление домашних задач.
- Назначение ответственного и срока выполнения.
- Изменение статуса задачи и просмотр списка выполненных дел.

## План развития
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
