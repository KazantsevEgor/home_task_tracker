## Назначение

**Трекер домашних задач** — приложение, которое помогает пользователю вести список домашних дел: добавлять задачи с указанием категории и дедлайна, отслеживать их статус и не пропускать сроки.

Консольная версия позволяет управлять задачами через меню в терминале. Веб-версия на Django отображает задачи и их карточки в браузере.

---

## Целевая аудитория

Пользователи, которым нужен простой инструмент для организации повседневных домашних дел без использования внешних сервисов и облачных платформ.

---

## Предметная область

Основной объект предметной области — **домашняя задача**. Задача описывается названием, категорией, дедлайном и статусом выполнения.

Пользователь может:
- добавлять задачи с названием, категорией и сроком выполнения;
- отмечать задачи выполненными и снимать отметку;
- искать задачи по подстроке названия;
- фильтровать задачи по категории;
- сортировать задачи по дедлайну;
- просматривать статус каждой задачи.

Статус задачи вычисляется автоматически:
- **«Задача выполнена»** — задача отмечена выполненной (`is_completed = true`);
- **«Задача просрочена»** — дедлайн прошёл, задача не выполнена;
- **«Задача в процессе»** — дедлайн ещё не наступил, задача не выполнена.

---

## Основные сущности

### Задача (Task)

Единственная сущность предметной области.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `int` | Уникальный числовой идентификатор, присваивается автоматически |
| `name` | `str` | Название задачи, например «Убрать кухню» |
| `category` | `str` | Категория задачи, например «Уборка», «Покупки», «Ремонт» |
| `deadline` | `str` (ISO 8601) | Дедлайн в формате `ГГГГ-ММ-ДД`, например `2026-10-15` |
| `is_completed` | `bool` | `true` — задача выполнена, `false` — ещё нет |

**Пример задачи:**

```json
{
  "id": 1,
  "name": "Убрать кухню",
  "category": "Уборка",
  "deadline": "2026-10-15",
  "is_completed": false
}
```

## Объектная модель

С ПР3 данные задач представлены не словарями, а объектами класса `Task` из модуля `models/task.py`.

### Класс `Task`

```python
from models import Task

task = Task(
    task_id=1,
    name="Убрать кухню",
    category="Уборка",
    deadline="2026-10-15",
)
```

**Атрибуты объекта:**

| Атрибут | Тип | Описание |
|---------|-----|----------|
| `task.id` | `int` | Идентификатор |
| `task.name` | `str` | Название |
| `task.category` | `str` | Категория |
| `task.deadline` | `str` | Дедлайн в формате ISO 8601 |
| `task.is_completed` | `bool` | Статус выполнения |

**Методы объекта:**

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `task.mark_completed()` | `None` | Отмечает задачу выполненной (`is_completed = True`) |
| `task.cancel_completion()` | `None` | Снимает отметку выполнения (`is_completed = False`) |
| `task.get_status()` | `str` | Возвращает текстовый статус задачи |
| `task.days_until_deadline()` | `int` | Количество дней до дедлайна (может быть отрицательным) |
| `task.to_dict()` | `dict` | Преобразует объект в словарь для сохранения в JSON |
| `Task.from_dict(data)` | `Task` | Создаёт объект `Task` из словаря (classmethod) |
| `str(task)` | `str` | Строковое представление вида `[1] Убрать кухню (Уборка) — до 2026-10-15 — Задача в процессе` |

**Пример работы:**

```python
task = Task(1, "Убрать кухню", "Уборка", "2026-10-15")

print(task.get_status())        # Задача в процессе
print(task.days_until_deadline()) # количество дней

task.mark_completed()
print(task.get_status())        # Задача выполнена
print(task.is_completed)        # True

task.cancel_completion()
print(task.is_completed)        # False
```

**Сериализация и десериализация:**

```python
# Объект → словарь → JSON
data = task.to_dict()

# JSON → словарь → объект
task = Task.from_dict(data)
```

Данные хранятся в `data/tasks.json`. При загрузке каждый словарь преобразуется в объект `Task` через `Task.from_dict()`. При сохранении объекты преобразуются обратно через `task.to_dict()`.

## Основные функции

### Консольная версия (модули Python)

| Функция | Модуль | Описание |
|---------|--------|----------|
| `add_task(tasks, name, category, deadline)` | `tasks.py` | Добавляет новую задачу в коллекцию |
| `find_task(tasks, query)` | `tasks.py` | Ищет задачи по подстроке в названии |
| `find_task_by_id(tasks, task_id)` | `tasks.py` | Находит задачу по числовому ID |
| `filter_tasks_by_category(tasks, category)` | `tasks.py` | Генератор: отдаёт задачи выбранной категории |
| `sort_tasks(tasks)` | `tasks.py` | Сортирует задачи по дедлайну (возвращает новый список) |
| `check_task_deadline(tasks, task_id, days_left)` | `tasks.py` | Проверяет, осталось ли не менее `days_left` дней до дедлайна |
| `complete_task(tasks, task_id)` | `completions.py` | Отмечает задачу выполненной; `False` если уже выполнена |
| `cancel_completion(tasks, task_id)` | `completions.py` | Снимает отметку выполнения |
| `is_task_completed(tasks, task_id)` | `completions.py` | Проверяет, выполнена ли задача |
| `load_tasks(filename)` | `storage.py` | Загружает задачи из JSON-файла → `list[Task]` |
| `save_tasks(filename, tasks)` | `storage.py` | Сохраняет задачи в JSON-файл |
| `input_int(prompt)` | `utils.py` | Безопасный ввод целого числа с повтором при ошибке |
| `input_date(prompt)` | `utils.py` | Безопасный ввод даты ISO 8601 с повтором при ошибке |
| `show_tasks(tasks)` | `main.py` | Выводит список задач в виде таблицы в терминале |
| `main()` | `main.py` | Основной цикл консольного меню |

### Консольное меню

```
=== Трекер домашних задач ===
1. Показать все задачи
2. Найти задачу по названию
3. Фильтр по категории
4. Показать задачи по дедлайну
5. Добавить задачу
6. Отметить задачу выполненной
7. Снять отметку выполнения
0. Выход
```

## Веб-интерфейс

Веб-версия реализована на Django 5.2 и отображает данные из `data/tasks.json` в браузере.

### Страницы

| URL | View-функция | Описание |
|-----|-------------|----------|
| `/` | `homepage.views.index` | Главная страница: описание приложения, кнопка-ссылка на задачи |
| `/tasks/` | `task_pages.views.tasks` | Список всех задач с цветными статус-бейджами |
| `/tasks/<int:task_id>/` | `task_pages.views.task_detail` | Карточка отдельной задачи |

Если задача с указанным `task_id` не найдена, возвращается HTTP-ответ со статусом **404**.

### Цветовые бейджи статусов

| Статус | Цвет Bootstrap |
|--------|---------------|
| Задача выполнена | `bg-success` (зелёный) |
| Задача просрочена | `bg-danger` (красный) |
| Задача в процессе | `bg-warning text-dark` (жёлтый) |

### Функция `page()` (`homepage/views.py`)

Формирует единый HTML-каркас для всех страниц:
- `<!DOCTYPE html>` + `<html lang="ru">`;
- метатег `charset=UTF-8`;
- метатег `viewport` для адаптивности Bootstrap;
- подключение Bootstrap 5.3 через CDN;
- навигационная панель с ссылками на все разделы;
- блок `<main class="container">` с содержимым страницы.

Используется всеми view-функциями: `index()`, `tasks()`, `task_detail()`.

### Маршрутизация URL

```
tracker/urls.py
├── path('', include('homepage.urls'))       →  /
│       homepage/urls.py
│       └── path('', views.index)            →  / (главная)
│
└── path('tasks/', include('task_pages.urls')) → /tasks/...
        task_pages/urls.py
        ├── path('', views.tasks)             → /tasks/
        └── path('<int:task_id>/', views.task_detail) → /tasks/1/
```

## Хранение данных

Данные хранятся в файле `data/tasks.json` в виде списка объектов JSON.

**Пример содержимого файла:**

```json
[
  {
    "id": 1,
    "name": "Убрать кухню",
    "category": "Уборка",
    "deadline": "2026-10-15",
    "is_completed": false
  },
  {
    "id": 2,
    "name": "Купить молоко",
    "category": "Покупки",
    "deadline": "2026-10-01",
    "is_completed": true
  },
  {
    "id": 3,
    "name": "Починить кран",
    "category": "Ремонт",
    "deadline": "2026-09-20",
    "is_completed": false
  }
]
```

**Принцип работы с данными:**

```
При загрузке:
  JSON-файл → list[dict] → list[Task]  (через Task.from_dict())

При сохранении:
  list[Task] → list[dict] → JSON-файл  (через task.to_dict())
```

Преобразование выполняется исключительно в модуле `storage.py`. Остальные модули работают только с объектами `Task`.

Если файл не найден или содержит повреждённые данные, `load_tasks()` возвращает пустой список — приложение запускается без ошибок.

## Описание модулей

### `models/task.py`

Содержит класс `Task` — основную единицу данных приложения. Инкапсулирует атрибуты задачи и методы работы с её состоянием. Конвертация между объектом и словарём JSON реализована через `to_dict()` и `from_dict()`.

### `tasks.py`

Функции работы с коллекцией задач `list[Task]`:
- `add_task()` — создаёт объект `Task` и добавляет в список; `id` вычисляется автоматически как `max(id) + 1`;
- `find_task()` — поиск по подстроке в поле `name` (регистронезависимый);
- `find_task_by_id()` — поиск по числовому `id`; используется веб-страницей карточки задачи;
- `filter_tasks_by_category()` — генератор, отдаёт задачи одной категории;
- `sort_tasks()` — сортировка по полю `deadline` с помощью `lambda`;
- `check_task_deadline()` — проверяет, осталось ли не менее `N` дней до дедлайна.

### `completions.py`

Функции управления статусом выполнения:
- `complete_task()` — вызывает `task.mark_completed()`, возвращает `False` если задача уже выполнена;
- `cancel_completion()` — вызывает `task.cancel_completion()`;
- `is_task_completed()` — возвращает значение атрибута `task.is_completed`.

### `storage.py`

Загрузка и сохранение данных:
- `load_tasks()` — читает JSON-файл, преобразует каждый словарь в объект `Task`; при ошибке возвращает `[]`;
- `save_tasks()` — преобразует объекты `Task` в словари и записывает в JSON.

### `utils.py`

Вспомогательные функции ввода:
- `input_int()` — повторяет запрос, пока пользователь не введёт корректное целое число;
- `input_date()` — повторяет запрос, пока не будет введена корректная дата в формате ISO 8601.

### `main.py`

Точка запуска консольной версии. Загружает задачи, отображает меню, вызывает функции из `tasks.py`, `completions.py`, `storage.py`. Не содержит бизнес-логики.

## Назначение модулей Django

### `tracker/settings.py`

Настройки Django-проекта:
- `INSTALLED_APPS` — зарегистрированы `homepage` и `task_pages`;
- `LANGUAGE_CODE = 'ru-RU'` — русская локализация;
- `TIME_ZONE = 'Europe/Moscow'` — московский часовой пояс;
- `DATABASES` — SQLite для служебных нужд Django.

### `tracker/urls.py`

Корневая маршрутизация: подключает URL-конфигурации приложений `homepage` и `task_pages`.

### `homepage/views.py`

Содержит две функции:
- `page(title, content)` — вспомогательная функция, формирует полный HTML-документ с Bootstrap 5.3 и навигацией; импортируется другими приложениями;
- `index(request)` — главная страница с описанием и кнопкой перехода к задачам.

### `task_pages/views.py`

Содержит view-функции задач:
- `tasks(request)` — загружает `list[Task]` из `data/tasks.json`, формирует список с цветными бейджами статусов;
- `task_detail(request, task_id)` — находит задачу по ID через `find_task_by_id()`, отображает карточку; если не найдена — возвращает HTTP 404.
