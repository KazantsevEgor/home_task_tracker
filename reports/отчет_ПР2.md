### 2. Индивидуальный проект

**Название проекта:** Трекер домашних задач

**Перечень реализованных функций:**

| Модуль | Функция | Назначение |
|---|---|---|
| `main.py` | `main()` | Точка запуска; основной цикл меню |
| `main.py` | `show_tasks()` | Вывод списка задач в виде таблицы |
| `tasks.py` | `add_task()` | Добавление задачи в список |
| `tasks.py` | `find_task()` | Поиск задач по подстроке названия |
| `tasks.py` | `filter_tasks_by_category()` | Фильтрация задач по категории (генератор) |
| `tasks.py` | `sort_tasks()` | Сортировка задач по дедлайну (lambda) |
| `tasks.py` | `check_task_deadline()` | Проверка остатка дней до дедлайна |
| `completions.py` | `complete_task()` | Отметить задачу выполненной |
| `completions.py` | `cancel_completion()` | Снять отметку выполнения |
| `completions.py` | `is_task_completed()` | Проверить, выполнена ли задача |
| `completions.py` | `check_status()` | Вернуть текстовый статус задачи |
| `storage.py` | `load_tasks()` | Загрузка задач из JSON-файла |
| `storage.py` | `save_tasks()` | Сохранение задач в JSON-файл |
| `utils.py` | `input_int()` | Безопасный ввод целого числа |
| `utils.py` | `input_date()` | Безопасный ввод даты |

**Структура модулей проекта:**
- `main.py` — точка запуска, меню приложения, вывод данных;
- `tasks.py` — функции работы с задачами (поиск, фильтрация, сортировка);
- `completions.py` — управление статусом выполнения задач;
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — вспомогательные функции безопасного ввода.

**Формат хранения данных:**
Задачи хранятся в файле `data/tasks.json` в виде списка словарей:
```json
[
  {
    "id": 1,
    "name": "Убрать кухню",
    "category": "Уборка",
    "deadline": "2026-09-17",
    "is_completed": false
  }
]
```
