### 2. Индивидуальный проект

**Название проекта:** Трекер домашних задач

**Описание изменений:**

Консольное приложение (ПР3) расширено веб-интерфейсом на Django 5.2. Данные задач из `data/tasks.json` отображаются в браузере. Веб-слой использует классы и функции из ПР3 без дублирования логики.

**Django-проект:** `tracker`

Создан командой:
```
django-admin startproject tracker .
```

**Настройки (`tracker/settings.py`):**

| Параметр | Значение |
|---|---|
| `LANGUAGE_CODE` | `ru-RU` |
| `TIME_ZONE` | `Europe/Moscow` |
| `USE_TZ` | `True` |

**Созданные Django-приложения:**

| Приложение | Назначение |
|---|---|
| `homepage` | Главная страница; содержит вспомогательную функцию `page()` — единый HTML-каркас с Bootstrap 5.3 и навигацией |
| `task_pages` | Страницы задач: список и карточка отдельной задачи |

**Реализованные страницы:**

| URL | View-функция | Описание |
|---|---|---|
| `/` | `homepage.views.index` | Главная страница с описанием проекта и кнопкой-ссылкой на задачи |
| `/tasks/` | `task_pages.views.tasks` | Список задач из `data/tasks.json` с цветными статус-бейджами |
| `/tasks/<int:task_id>/` | `task_pages.views.task_detail` | Карточка задачи; если ID не найден — HTTP 404 |

**Маршрутизация:**

Корневой `tracker/urls.py` включает маршруты приложений:
```python
path('', include('homepage.urls'))
path('tasks/', include('task_pages.urls'))
```

Каждое приложение имеет собственный `urls.py`.

**Функция `page()` (`homepage/views.py`):**

Формирует единый HTML-каркас всех страниц: DOCTYPE, метатеги, подключение Bootstrap 5.3 через CDN, навигационная панель. Остальные приложения импортируют её и передают заголовок и содержимое страницы.

**Добавленная функция `find_task_by_id()` (`tasks.py`):**

Поиск объекта `Task` по числовому идентификатору; используется view-функцией `task_detail()`. Возвращает `Optional[Task]`.

### 4. Вывод

В ходе выполнения ПР5 консольное приложение «Трекер домашних задач» получило веб-интерфейс на Django. Веб-слой не дублирует логику ПР3: view-функции загружают данные через `storage.load_tasks()` и работают с объектами `Task`, реализованными в ПР3. Функция `page()` обеспечивает единый HTML-каркас всех страниц с подключением Bootstrap 5.3. Маршрутизация URL организована на двух уровнях. Приложение успешно запускается командой `python manage.py runserver` и отображает список задач и карточки отдельных задач в браузере.
